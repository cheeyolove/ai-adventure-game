# 🦭 AI 탐험대!

**진짜 같아도 한 번 더 확인해요!** — 초등학교 3~4학년 AI 리터러시 체험형 교육 게임

바다표범 탐험대원이 되어 AI 탐험 바다섬을 돌며 **직접 조사하고, 소문을 멈추고, 카드를 배달하고, 자료를 비교하고, 사진 속 개인정보를 가리는**
다섯 가지 미니게임을 해결해요. 친구들과 같은 방에서 함께 탐험하고, 모은 코인으로 바다표범을 꾸밀 수 있어요.

- 학습 기준: 「AI리터러시_Part3_기본」 워크북 1차시 PPT (19쪽) — 학습 목표와 판단 기준은 그대로, 활동 방식만 체험형
- 수업: 1차시 PPT + 「AI 안전 약속 포스터」 → **2차시 이 게임** (포스터 사진 업로드는 필요 없어요)
- 게임 주소: https://cheeyolove.github.io/ai-adventure-game/ (시작 파일: 저장소 루트의 `index.html`)

## 게임 흐름 (목표 8~12분, 실제 학생 플레이 시간은 미측정)

탐험대장(세 가지 약속 카드) → ① 해변 → ② 소문 바다(부두) → ③ 질문 마을 → ④ 도서관 연구소 → ⑤ 공유 광장 → 등대 최종 인증 → 춤추는 바다표범 + 인증서

| 미니게임 | 학습 목표 | 하는 일 |
| --- | --- | --- |
| ① 수상한 영상 탐정 | AI 영상도 진짜처럼 보일 수 있어요 | 돋보기를 끌어 단서 3개(누가 만들었나·원래 영상·다른 자료) 찾기 → 결론 고르기 → ⭕/❌ 탐정 도장 5장 (가족사진 "무조건" 문항 포함) |
| ② 소문을 멈춰라! | 멈춰요 — 바로 믿거나 퍼뜨리지 않기 | 떠다니는 소문 물방울 3개를 눌러/✋버튼으로 멈추고 확인 방법 고르기 (시간 실패 없음, 닿으면 다시 돌아옴) |
| ③ 누구에게 물어볼까? | 물어봐요 — 믿을 만한 어른 | 상황 카드 3장을 선생님·부모님·학교 공식 안내·익명 댓글에게 끌어서 배달 (알맞은 대상 여러 명 인정) |
| ④ 사실 확인 연구소 | 다시 찾아봐요·확인해요·비교해요 | 정보 카드 뒤집기 → 출처 도장 → "출처가 분명한 자료 / 추가 확인 필요" 상자에 끌어 분류 → 공식 알림 날짜 비교 → 저울(사람 수 vs 출처) |
| ⑤ 사진 속 비밀을 찾아라! | 올리기 전에 확인 | 친구 얼굴·이름표 찾기 → 스티커 끌어서 가리기 → 전후 비교 막대 → 체크리스트 → 올릴 곳 고르기 |
| 최종 인증 | 세 가지 행동 | 상황 ↔ 행동 카드 잇기 → 약속 카드 순서 놓기(멈춘 뒤 순서는 유연하게 인정) |

정답 원칙: "AI라서 거짓", "진짜 사진이라서 무조건 사실", "가족사진이라서 무조건 사실"로 판단하지 않고, **"확인이 필요하다"와 "거짓이다"를 구별**해요.
모든 인물·영상·사진·학교 알림은 가상이며, 연구소 화면에 "가상 학교·가상 알림"이라고 표시해요.

## 코인과 바다표범 꾸미기 상점

- 미니게임을 **처음** 완료하면 20코인 × 5 + 최종 인증 30코인 = **총 130코인**. 틀려도 코인을 빼앗지 않아요.
- 완료한 미니게임은 「다시 공부하기」로 반복할 수 있고, 이때는 코인이 없어요.
- 상점(🛍️): 꽃 머리핀 20 · 선원 모자 30 · 별 머리띠 35 · 동그란 안경 25 · 선글라스 35 · 빨간 리본 20 · 파란 목도리 30 · 노란 우비 40 · 탐정 코트 50 · 분홍 드레스 45 · 작은 가방 35 · 돋보기 25 · 조개 지팡이 35 · 반짝이 효과 50 (탐험대 모자·탐험 가방 기본 제공)
- 미리 입어 보기, 중복 구매 방지, 코인 부족 시 구매 불가, 같은 부위는 하나만 착용, 새로고침 후 유지.

## 함께 탐험 (실시간 동시접속)

- 별명 화면에서 「친구들과 함께 탐험하기」(기본 켜짐) + 방 코드(기본 **바다**)
- 연결: PeerJS(WebRTC). 공용 서버에는 방 검색 기능이 없어서, 방 코드를 UTF-8 16진수로 바꾼 **고정 방장 아이디**(`aiexplorers-v2-r` + `ebb094eb8ba4` = 바다)를 먼저 차지한 사람이 방장이 되고, 나머지는 `unavailable-id` 오류를 받으면 그 아이디로 접속해요. 방장이 0.2초마다 모두의 위치·이름·착용 아이템을 중계하고, 방장이 나가면 남은 사람 중 새 방장이 자동으로 생겨요.
- 주고받는 정보: 별명, 위치, 방향, 착용 아이템, 미니게임 중 표시. (코인·구매 기록·미션 기록은 보내지 않아요)
- 연결이 안 되면 🔴 표시와 안내가 나오고, 혼자서도 모든 미니게임을 할 수 있어요.
- 학교 인터넷이 WebRTC를 막으면 연결이 안 될 수 있어요. 이때는 `js/config.js` 의 `PEER_SERVER` 로 학교 PeerJS 서버를 지정할 수 있어요.

## 저장 · 교사용 화면

- 기기 브라우저 저장소(`ai-explorers:v1`, v2 형식)에 별명별 저장. 첫 버전 기록은 자동으로 새 미션 순서로 옮기고, 이미 끝낸 미션 코인을 한 번 넣어 줘요.
- 학생 화면에는 교사용 링크가 없어요. `teacher.html` 은 주소를 직접 입력해 열어요.
- **보안 상태**: `teacher.html` 은 공개 파일이고 로그인·비밀번호 같은 접근 제어가 없어요. 대신 서버에 모인 학생 기록이 없고, 그 기기에 저장된 기록과 선생님이 붙여 넣은 결과 코드만 보여 줘요. (`noindex` 설정)
- (선택) Google 시트로 결과 받기: [docs/teacher-results.md](docs/teacher-results.md) — 기본값은 꺼짐

## 파일 구조

```
index.html / teacher.html
css/style.css
js/config.js     저장 키 · (선택) 결과 전송 · (선택) 연결 서버
js/pixel.js      픽셀 아트 (바다표범 + 착용 아이템, 해양 친구, 배지)
js/world.js      바다섬 지도 · 충돌 · 길찾기
js/missions.js   체험형 미니게임 5개 + 최종 인증
js/shop.js       바다표범 꾸미기 상점 · 옷장
js/net.js        함께 탐험 (PeerJS)
js/main.js       저장 · 코인 · 이동 · 대화 · 지도 · 다른 학생 표시
js/teacher.js    교사용 기록
vendor/          PeerJS 1.5.4 (MIT)
```

빌드 과정 없이 정적 파일 그대로 GitHub Pages(`main` / `(root)`)로 배포해요. 로컬 실행: `python3 -m http.server 8000`
