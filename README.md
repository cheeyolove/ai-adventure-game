# 🦭 AI 탐험대!

**진짜 같아도 한 번 더 확인해요!** — 초등학교 3~4학년 AI 리터러시 교육 게임

바다표범 탐험대원이 되어 AI 탐험 바다섬의 다섯 구역을 돌며, 이상한 영상·얼굴이 바뀐 사진·인터넷 소문·사진 공유 상황을 만나고
**멈춰요 · 물어봐요 · 다시 찾아봐요** 를 직접 실천하는 2D 픽셀 아트 탐험 게임입니다.

- 학습 기준: 「AI리터러시_Part3_기본」 워크북 1차시 PPT (19쪽)
- 수업 흐름: 1차시 PPT 수업 + 「AI 안전 약속 포스터 만들기」 → **2차시 이 게임으로 적용·복습**
- 포스터 사진 촬영·업로드는 필요 없어요. 게임은 포스터와 따로 즐길 수 있어요.

## 게임 흐름 (약 8~12분 목표, 실제 학생 플레이 시간은 미측정)

1. 시작 화면 → 별명 정하기 (실명 대신 별명)
2. 🦭 탐험대장: 학습 목표 소개 + **세 가지 약속 카드** (1차시 포스터와 연결)
3. 🎬 **신기한 영상 해변** — 🐙 문어 박사 → 🔍 탐정 돋보기
4. 🏘️ **질문하는 마을** — 🐢 거북 선생님 (+ 🐟 소문 물고기) → 🐚 질문 조개
5. 📚 **사실 확인 도서관** — 🐧 확인 도우미 펭귄 → 📖 비교 책갈피
6. 📷 **안전한 공유 광장** — 🪼 인터넷 소문 해파리 → 🛡️ 안전 공유 방패
7. 🏅 **AI 탐험대 인증 센터(등대)** — 최종 시험(등대 불 5개 켜기) → 🏅 인증 메달
8. 마지막 연출 「진짜 같아도 한 번 더 확인해요! 멈춰요 · 물어봐요 · 다시 찾아봐요」 → **AI 탐험대 인증서**

미션은 순서대로 열려요. 노란 화살표가 다음 목적지를 알려 줍니다.

## 미션과 문제 (총 18단계)

| 미션 | 단계 | 문제 유형 |
| --- | --- | --- |
| 1 영상 해변 | ① 말하는 강아지 영상: 가장 먼저 할 일 (3지) | 상황 보고 행동 고르기 |
|  | ② 왜 한 번 더 확인할까? (2×2) | 이유 고르기 |
|  | ③ 얼굴이 바뀐 친구 사진: 알맞은 행동 모두 (4개 중 3개) | 복수 선택 |
|  | ④ O·X 4문장 (AI도 유용할 수 있음 / 이상한 점만으로 확정 못 함 / 진짜 사진에도 틀린 설명) | O·X |
| 2 질문 마을 | ① 상황 3장 ↔ 도움 요청 대상 4장 선 잇기 | 상황-대상 연결 |
|  | ② 소문 물고기에게 할 말 (2×2) | 상황 보고 행동 고르기 |
|  | ③ 멈춰요·확인해요·비교해요 ↔ 뜻 (PPT 8~9쪽) | 낱말-뜻 연결 |
| 3 도서관 | ① 자료 A(익명 글)·B(가상 학교 공식 알림)·C(친구 메시지) 출처 확인 → 가장 알맞은 자료 | 자료 비교 · 출처가 분명한 자료 찾기 |
|  | ② 두 곳에서 같은 말 → 사실로 확정? | 판단 근거 확인 |
|  | ③ 정보가 서로 다를 때 (4개 중 2개) | 복수 선택 |
| 4 공유 광장 | ① 사진 속 확인할 곳 누르기 (친구 얼굴·이름표) | 사진 속 터치 |
|  | ② 이 사진을 어떻게 할까? (2지) → 고친 사진 보기 | 상황 보고 행동 고르기 |
|  | ③ 공유 전 체크리스트 완성 (6개 중 4개) | 체크리스트 완성 |
| 5 최종 시험 | ① AI 영상이 실제처럼 보일 수 있나요? ② 놀라운 내용 바로 보내기? ③ 확인 행동 두 가지 ④ 친구 얼굴 사진 허락 없이 공유? ⑤ 약속 카드 순서 | 네/아니요 · 2×2 · 복수 선택 · 네/아니요 · 순서 배열 |

### 정답 설계 원칙

- "AI = 가짜"로 처리하지 않아요. **"확인이 필요하다"와 "거짓이다"를 구별**합니다. (예: "소문은 무조건 거짓말이야"는 오답)
- 이상한 영상이라고 AI가 만든 것이라 확정하지 않고, 진짜처럼 보인다고 실제라고 확정하지 않아요.
- AI로 만든 콘텐츠도 유용할 수 있고, 실제 사진에도 잘못된 설명이 붙을 수 있다는 점을 O·X로 다뤄요.
- 가족이 보낸 사진을 "무조건 믿는다/의심한다"로 정답을 정하는 문제는 넣지 않았어요.
- 공식 자료도 **날짜**를 함께 확인하도록 했어요. 도서관 자료는 모두 "게임 속 가상 학습 사례"라고 표시해요.
- 순서 문제는 「멈춰요 → 물어봐요 → 다시 찾아봐요」가 기본이지만, 멈춘 뒤 다시 찾아보고 물어보는 순서도 정답으로 받아 주며
  "실제 생활에서는 함께 해도 좋아요"라고 안내해요.
- 정답이 여러 개일 수 있는 문제는 복수 선택(모두 고르기)이나 여러 연결을 인정하도록 만들었어요.
- 모든 인물(콩이·몽실이·방울이 등), 학교(바다초등학교), 영상·사진은 가상입니다. 실제 사진·실제 딥페이크 사례는 쓰지 않아요.

## 조작

- **PC**: 방향키/WASD 이동, 친구 근처에서 `E`(또는 Space/Enter)로 대화, 문제는 마우스 또는 숫자 1~4
- **태블릿**: 왼쪽 아래 가상 방향키, 가고 싶은 곳이나 친구를 **눌러서 이동**, 💬 버튼으로 대화
- 화면 확대·스크롤 방지, 가로 화면 최적화(세로일 때 안내)

## 저장

- 기기의 브라우저 저장소에 별명별로 저장 (`ai-explorers:v1`): 미션 완료 여부, 다시 도전 횟수, 미션별 걸린 시간, 플레이 시간, 완료 시각, 지도 위치
- 새로고침해도 이어서 할 수 있고, 한 기기에서 여러 학생이 별명을 골라 이어 할 수 있어요.
- 메뉴 → 「처음부터 다시 하기」로 해당 별명 기록만 초기화
- 사진·실명·얼굴 등 개인정보는 수집하지 않아요. 기본 설정에서는 서버로 보내는 데이터가 없습니다.

## 선생님용 기록 (`teacher.html`)

- 이 기기에 저장된 학생 기록 표: 별명, 미션별 완료, 전체 완료, 다시 도전 횟수(합계·미션별), 플레이 시간, 완료 시각, CSV 저장
- 「결과 코드 모으기」: 학생 인증서의 `AIX1-…` 코드를 붙여 넣어 여러 기기 결과를 서버 없이 모으기
- (선택) Google Apps Script로 실시간 받기: [docs/teacher-results.md](docs/teacher-results.md) — 기본값은 꺼짐

## 파일 구조

```
index.html          게임 화면
teacher.html        선생님용 기록 화면
css/style.css       해양 파스텔 테마 UI
js/config.js        저장 키, (선택) 결과 전송 주소
js/pixel.js         픽셀 아트 도구 + 바다표범·해양 친구·배지 그림 (코드로 그림, 외부 이미지 없음)
js/world.js         AI 탐험 바다섬 지형·건물·충돌·길찾기
js/missions.js      다섯 미션 내용 + 문제 유형 엔진
js/main.js          저장·이동·카메라·대화·HUD·인증서
js/teacher.js       선생님용 기록 화면
docs/teacher-results.md  (선택) Google 시트로 결과 받기
```

빌드 과정이 없어요. 정적 파일 그대로 GitHub Pages에 올리면 됩니다.

1. GitHub에서 빈 저장소 `cheeyolove/ai-adventure-game` 를 만듭니다. (README 추가 없이)
2. 이 폴더를 푸시합니다: `git remote add origin https://github.com/cheeyolove/ai-adventure-game.git` → `git push -u origin main`
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save
4. 잠시 후 `https://cheeyolove.github.io/ai-adventure-game/` 에서 열립니다.
